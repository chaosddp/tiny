# tiny


## home dir

~/.tiny

### config file

default configurations: ~/.tiny/config.json

created automatically when you first run tiny with default configurations.


each project has its own config file: .tiny/config.json, which will override the default configurations, generated by command `tiny init` in the project root directory.

```bash

tiny init --tools t1,t2,t3 --extensions e1,e2,e3 --model default_model_to_use

```

### tools

default tools: ~/.tiny/tools.

each tool folder can be a tool definition, or a tool package that contains multiple tool definitions. tool package will make it easier to manage tools for different projects.

### extensions

extensions are used to extend the functionality of tiny. default extensions: ~/.tiny/extensions.

each extension folder is a package that can contain different extension type, such as tool executor, chat client, etc.

## usage

### init

```bash

# this command will create a .tiny folder in current folder by default, and generate an empty config.json in it.
tiny init [--model default_model_to_use] [--tools collection1,collection2] [--extensions extension1,extension2]

```

### session

by default, all the chat in current folder will share same chat session (default session), you can also create a new session, it will backup current default session by renaming it to `session_<timestamp>`, and create a new session as the default one.


all the session will be saved in .tiny/session folder.


```bash

# list all the sessions in current folder
tiny session list

# create a new session and make it as the default one (backup the current default session)
tiny session new

# show the content of a specific session
tiny sessio show --name session_name

```

### chat

The default command of tiny is chat.

```bash

# if there is not any options, it will use the default model to chat with you, all the content after the command will be treated as the user message.
tiny what can you do?

# chat with a specific model, you can use the following command:
tiny --model model_name what can you do?

# chat and show the reasoning process, you can use the following command:
tiny --reasoning why is the sky blue?

# chat with a specific session, you can use the following command:
tiny --session session_name what did i ask you yesterday?

# chat with images, you can use the following command:
tiny --image page/to/img,/path/to/img2 what is the content of these images?

# by default, each tool call will be treated as unsafe, tiny will prompt you to confirm before calling the tool, if you want to skip the confirmation, you can use the following command:
tiny --allow what is the weather today?

# you can also set the thinking effort level for the model to use, low, medium or high, the default is medium, you can use the following command:
tiny --thinking-effort low|medium|high what is the weather today?

# show the token usage at the end
tiny --usage who are you?

```
